# 快照管家（SillyTavern 原生扩展）

SillyTavern / TauriTavern（PC + 手机竖屏）原生扩展插件，通过扩展 URL 直接安装并支持酒馆内置更新。

## 安装方式

1. 打开 SillyTavern 的 **扩展（Extensions）** → **安装扩展（Install Extension）**。
2. 粘贴仓库地址：`https://github.com/Mio-Ame/user-persona-picker`
3. 安装完成后刷新页面。

入口位置：
- **快捷悬浮球**：默认吸附屏幕边缘，支持拖动贴边与位置记忆；轻点弹出「快捷切换快照」浮层，一键切换快照、快速保存或打开完整面板（可在面板顶栏或扩展设置中随时隐藏/显示）。
- **魔法棒菜单 / 扩展设置**：点击 **「快照管家」** 打开完整面板。

## 核心特点

- **清晰 5 页组装 + 底部常驻保存栏**：`快照` / `User` / `世界书` / `预设` / `正则` 各自独立，底部始终常驻「保存快照」与「更新当前快照」。
- **User 原地改名与换姓防增殖**：
  - 在「User」页支持直接对当前 User **原地改名**（立即生效为 `{{user}}`，不在酒馆多出新分身）；
  - 同一个 User 槽位下的内部描述版本支持绑定不同**显示名**（如按剧情换姓后的全名），切换版本或应用快照时自动原地切换名字与正文，彻底避免酒馆内堆出一堆同名/换姓分身；
  - 「整理分身」自动识别同名与同尾字换姓分身，一键收回为内部版本并同步删除后端头像文件，附带一键清理未命名残留头像。
- **预设条目原地展开**：在「预设」页与「快照详情 → 预设」中点击任意条目，直接在条目下方展开正文与编辑框（无需跳出遮挡弹窗），并完整同步预设分组折叠与分组总开关状态。
- **快照详情即开即改**：打开快照详情页，预设分组总开关、预设条目开关、世界书条目开关与正则开关均可直接拨动并实时保存（支持读取非当前激活预设）。
- **与 `worldbook-organizer` 双向解耦联动**：
  - 自动按分组、别名、自定义排除分组与**角色世界书标题模式**（角色名 + 小字原世界书标题 / 仅角色名 / 原名）呈现世界书列表，未安装整理插件时自动回退读取当前酒馆角色绑定；
  - 在世界书页提供「整理分组」一键直达入口，实时监听 `wbo:worldbook-renamed`、`wbo:worldbook-deleted`、`wbo:settings-updated` 事件，改名自动同步所有快照、删书自动标黄提示、改设置免刷新生效。
- **统一 6 套低饱和配色**：内置「素纸」「青岚」「暖砂」「淡樱」「跟随酒馆」「深色夜间」，与 `worldbook-organizer` 视觉风格对齐，面板与悬浮球同步换色。
- **按聊天 / 角色自动切回**：支持绑定当前聊天或角色默认（优先级：聊天 > 角色），提供「自动切换」总开关（默认开启，随时可暂停）。
