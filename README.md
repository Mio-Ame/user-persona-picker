# User 组装与快照（SillyTavern 原生扩展）

SillyTavern / TauriTavern（PC + 手机竖屏）原生扩展插件，通过扩展 URL 直接安装并支持酒馆内置更新。

## 安装方式

1. 打开 SillyTavern 的 **扩展（Extensions）** → **安装扩展（Install Extension）**。
2. 粘贴仓库地址：`https://github.com/Mio-Ame/user-persona-picker`
3. 安装完成后刷新页面。

入口位置：
- **快捷悬浮球**：默认吸附屏幕边缘，支持拖动贴边与位置记忆；轻点弹出「快捷切换快照」浮层，一键切换快照、快速保存或打开完整面板（可在面板顶栏或扩展设置中随时隐藏/显示）。
- **魔法棒菜单 / 扩展设置**：点击 **「User 组装与快照」** 打开完整面板。

## 核心特点

- **清晰 5 页组装 + 底部常驻保存栏**：`快照` / `User` / `世界书` / `预设` / `正则` 各自独立，底部始终常驻「保存快照」与「更新当前快照」。
- **快照详情即开即改**：打开快照详情页，预设分组总开关、预设条目开关、世界书条目开关与正则开关均可直接拨动并实时保存；点标题即可全屏阅读正文（支持读取非当前激活预设）。
- **与 `worldbook-organizer` 双向解耦联动**：
  - 自动按分组、别名与自定义排除分组呈现世界书列表，并在世界书页提供「整理分组」一键直达入口；
  - 实时监听 `wbo:worldbook-renamed`、`wbo:worldbook-deleted`、`wbo:settings-updated` 事件——真实改名时自动同步更新所有快照与置顶引用，删书时自动在受影响快照中标记提示，改分组后免刷新即时生效。
- **预设条目分组同步**：完整读写预设的分组折叠与分组总开关状态，支持一键写入预设文件及随快照完整还原。
- **解决同名 User 增殖**：酒馆内每个名字只保留 1 个 Persona，同名字不同设定存为插件内部描述版本（支持行级差异对比）；「整理分身」可一键收回旧分身并同步删除后端头像文件，附带一键清理未命名残留头像。
- **统一 6 套低饱和配色**：内置「素纸」「青岚」「暖砂」「淡樱」「跟随酒馆」「深色夜间」，与 `worldbook-organizer` 视觉风格对齐，面板与悬浮球同步换色。
- **按聊天 / 角色自动切回**：支持绑定当前聊天或角色默认（优先级：聊天 > 角色），提供「自动切换」总开关（默认开启，随时可暂停）。
