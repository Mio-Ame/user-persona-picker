# User 组装与快照（user-persona-picker）

适用于 SillyTavern / TauriTavern（PC + 手机竖屏）的 **酒馆助手（JS-Slash-Runner）** 全局脚本。

将「自由组装 User 人设 / 世界书 / 预设 / 正则」「全量状态一键快照」「同名 User 防增殖整理」整合在同一个轻量液态玻璃面板中。

## 操作流程

1. **组装**：按需在顶部切换 **User / 世界书 / 预设 / 正则** 四个独立标签页调整开关与正文。
2. **保存快照**：底部操作栏常驻 **「保存快照」**（已绑定时同时提供「更新当前快照」），在任意页面调完随时一键存盘。
3. **切换与绑定**：在 **「快照」** 页点「应用」一键恢复，点「查看」在浮层预览所有已开条目正文，或点「绑定」让切换聊天/角色时自动切回。

## 核心特点

- **全量一键快照**：自由勾选保存范围——**User 人设、世界书绑定与条目开关、预设（含 BaiBai Tools 分组开关与提示词开关）、正则开关**；支持自定义分组、覆盖更新、JSON 备份与导入。
- **按聊天 / 角色自动切回**：支持绑定当前聊天或当前角色默认（优先级：聊天 > 角色），顶部「自动切换」开关默认开启，随时可暂停。
- **解决 User 增殖**：酒馆内每个名字只保留 1 个 User Persona；同一名字的不同设定作为**内部描述版本**保存在插件内，切换时原地更新并自动保留切换前备份，支持行级差异对比，并提供「整理分身」一键收回旧的同名/分身 User。
- **原生兼容 BaiBai Tools 预设分组**：自动读取 `baibaiToolkit.presetPromptGroups`，按原顺序折叠分组并支持分组总开关、全部展开/折叠、按分组名与正文搜索，以及快照同步记录/恢复分组状态。
- **不破坏原格式**：快照仅记录引用与开关状态，应用时绝不覆盖修改过的世界书/预设/正则正文，也不向 Persona 拼接文本或强加外层标签。

## 安装方式

前置需求：已安装并启用 **酒馆助手（JS-Slash-Runner）**。

### 方式一：GitHub 自动更新壳（推荐，导入一次即可）

1. 下载本仓库的 `user-persona-picker-loader.json`。
2. 在酒馆助手 → 脚本库中导入该文件并启用。
3. 以后仓库更新时，刷新酒馆即可自动拉取最新版。

### 方式二：离线单文件

1. 下载本仓库的 `user-persona-picker.json`。
2. 在酒馆助手 → 脚本库中导入并启用。

导入后，从酒馆扩展菜单点击 **「User 组装与快照」**，或点击脚本按钮 **「User人设」** 即可打开面板。
