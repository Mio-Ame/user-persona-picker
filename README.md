# User 组装与快照（SillyTavern 原生扩展）

SillyTavern / TauriTavern（PC + 手机竖屏）原生扩展插件，**无需酒馆助手（JS-Slash-Runner）**，直接通过扩展 URL 安装并支持酒馆内置一键更新。

## 安装方式

1. 打开 SillyTavern 的 **扩展（Extensions）** → **安装扩展（Install Extension）**。
2. 粘贴仓库地址：`https://github.com/Mio-Ame/user-persona-picker`
3. 安装完成后刷新页面。

入口位置：输入框左侧魔法棒菜单中的 **「User 组装与快照」**，或在扩展设置面板中点击 **「打开面板」**。

## 使用流程

1. **组装**：在顶部 5 个独立页签中自由切换与调整：**`User` / `世界书` / `预设` / `正则`**。
2. **保存快照**：底部常驻操作栏随时可见主按钮 **「保存快照」**（已绑定快照时同时显示「更新当前快照」），调完即存。
3. **查看与切换**：在 **`快照`** 页点 **「查看」** 打开全屏分标签详情页（预设页按 BaiBai Tools 分组折叠展示、直接点击条目即可看正文，支持读取非当前激活预设），点 **「应用」** 一键切换，或点 **「绑定」** 让切换聊天/角色时自动切回。

## 核心特点

- **原生读取全部预设与 BaiBai Tools 分组**：完整支持 `baibaiToolkit.presetPromptGroups` 分组折叠、分组总开关与运行时同步；在快照详情页也能像浏览预设面板一样按分组查看任意预设的生效状态与条目正文。
- **全量状态一键快照**：自由勾选保存范围（User 人设、世界书绑定与条目开关、预设分组与提示词开关、正则开关）；只记录引用与开关状态，应用时绝不覆盖修改过的世界书/预设/正则正文。
- **按聊天 / 角色自动切回**：支持绑定当前聊天或角色默认（优先级：聊天 > 角色），顶部提供「自动切换」总开关（默认开启，随时可暂停）。
- **解决同名 User 增殖**：酒馆里每个名字只保留 1 个 Persona；同一名字的不同设定作为插件内**内部描述版本**原地切换并自动留存「切换前备份」，支持行级差异对比与「整理分身」一键收回旧分身。
- **原生持久化与自动迁移**：数据保存在酒馆 `settings.json`（`extension_settings.user_persona_snapshot`），支持 JSON 备份与导入，并自动迁移旧版脚本的本地快照。
