# 快照管家（SillyTavern 原生扩展）

SillyTavern / TauriTavern（PC + 手机竖屏）原生扩展插件，通过扩展 URL 直接安装并支持酒馆内置更新。

## 安装方式

1. 打开 SillyTavern 的 **扩展（Extensions）** → **安装扩展（Install Extension）**。
2. 粘贴仓库地址：`https://github.com/Mio-Ame/user-persona-picker`
3. 安装完成后刷新页面。

入口位置：
- **快捷悬浮球**：默认吸附屏幕边缘，支持拖动贴边与位置记忆；轻点弹出「快捷切换快照」浮层，直接展示每个快照的名称与备注，点名称查看详情，点右侧清晰的 **「应用」** 按钮才执行切换。
- **魔法棒菜单 / 扩展设置**：点击 **「快照管家」** 打开完整面板。

## 核心特点

- **自由选择快照包含内容 + 智能自动命名 + 批量管理**：
  - 保存快照时可自由勾选要包含的模块（`User` / `世界书` / `预设` / `API 连接配置` / `正则`），勾选习惯自动记住并在编辑快照时随时增减；
  - 保存时自动按当前角色名、User 名与预设名生成默认标题与一键快捷命名词（无需手工输入），并支持「批量管理」多选二次确认批量删除快照；
  - API 快照仅保存连接配置名、来源与模型标识，绝不保存任何 API 密钥。
- **免进聊天远程绑定角色与聊天档**：
  - 打开任意快照的「绑定」，无需先切进对应角色/聊天窗口，即可直接搜索或从列表勾选任意角色设为默认，或选中任意角色一键扫描其全部聊天档并绑定指定聊天记录。
- **世界书与预设条目统一原地展开 + 标签异常一键定位**：
  - 世界书页、预设页及快照详情页点击任意条目，均在正下方原地展开查看/编辑（不弹遮挡弹窗）；
  - 检测到未闭合或重复包裹标签时，点击提示条直接滚动定位并展开对应条目；世界书顶栏「全局启用 / 已全局启用」清晰标示是否对所有聊天生效。
- **预设版本升级与批量同步（0.17 → 0.18 无损迁移 + 新条目一键同步）**：
  - 支持同预设新增条目一键批量同步到多份快照，以及跨版本无损迁移（即使旧预设已误删仍可匹配），新增条目默认跟随酒馆原生预设开关并支持一键撤销。
- **User 搜索、原地改名与清晰分身整理**：
  - 支持关键词检索所有 User 名称与人设正文、原地改名、一槽多姓内部版本；「整理分身」自动把相似分身置顶并支持展开查看完整正文。
- **快照显式保存与缺失项弥补**：
  - 覆盖更新带二次确认；快照详情页支持显式「保存修改」与未保存提醒；应用前检测 User / 世界书 / 预设 / API 缺失时绝不删快照，支持原地替换或跳转弥补。
- **与 `worldbook-organizer` 双向解耦联动**：
  - 自动按分组、别名、自定义排除分组与角色世界书标题模式呈现世界书列表，实时监听改名/删书/配置变动事件并支持一键直达整理面板。
- **统一 6 套低饱和配色**：内置「素纸」「青岚」「暖砂」「淡樱」「跟随酒馆」「深色夜间」，面板与悬浮球同步换色。
