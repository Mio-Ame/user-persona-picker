# 快照管家（SillyTavern 原生扩展）

SillyTavern / TauriTavern（PC + 手机竖屏）原生扩展插件，通过扩展 URL 直接安装并支持酒馆内置更新。

## 安装方式

1. 打开 SillyTavern 的 **扩展（Extensions）** → **安装扩展（Install Extension）**。
2. 粘贴仓库地址：`https://github.com/Mio-Ame/user-persona-picker`
3. 安装完成后刷新页面。

入口位置：
- **快捷悬浮球**：默认吸附屏幕边缘，支持拖动贴边与位置记忆；轻点弹出「快捷切换快照」浮层，直接展示每个快照的名称与备注，点名称查看详情，点右侧清晰的 **「应用」** 按钮才执行切换。
- **魔法棒菜单 / 扩展设置**：点击 **「快照管家」** 打开完整面板。

## 核心特点

- **清晰 5 页组装 + 底部常驻保存栏**：`快照` / `User` / `世界书` / `预设` / `正则` 模块高度统一，固定尺寸弹窗不跳动，底部常驻「保存快照」与「更新当前快照」（覆盖更新均带二次确认）。
- **免进聊天远程绑定角色与聊天档**：
  - 打开任意快照的「绑定」，无需先切进对应角色/聊天窗口，即可直接搜索或从列表勾选任意角色设为默认，或选中任意角色**一键扫描其全部聊天档**并绑定指定聊天记录，已绑定的全部项集中展示并可一键解绑。
- **预设版本升级与批量同步（0.17 → 0.18 无损迁移 + 新条目一键同步）**：
  - 支持同预设新增条目一键批量同步到多份快照，以及预设跨版本迭代迁移（即使旧预设已误删，快照内自动留存的条目 ID 与标题清单仍可完成匹配）；
  - 三级智能匹配（ID 直连 → 归一化标题 → 手动关联），新增条目默认跟随酒馆原生预设开关，并支持一键撤销上次同步。
- **User 搜索、原地改名与清晰分身整理**：
  - 「User」页支持按关键词检索所有 User 名称、内部版本名及人设正文，支持原地改名与一槽多姓版本切换；
  - 「整理分身」自动把重名/换姓等相似分身置顶排列，支持筛选与展开查看完整人设正文，对比清晰后再勾选收回并同步清理残留头像。
- **预设分组默认折叠 + 条目原地展开**：
  - 预设分组默认收起（顶栏与扩展设置均带「默认折叠」开关），点击任意条目在正下方原地展开正文与编辑区。
- **快照编辑、显式保存与缺失项弥补**：
  - 支持编辑快照名称、分组与备注；快照详情页修改开关后提供「保存修改」按钮与未保存离开提醒；
  - 应用快照前自动核对缺失项，绝不删快照，支持原地替换、批量迁移旧预设、跳转对应页面弥补或跳过缺失项继续应用。
- **与 `worldbook-organizer` 双向解耦联动**：
  - 自动按分组、别名、自定义排除分组与角色世界书标题模式呈现世界书列表，分组展开互不挤压且弹窗尺寸锁定；
  - 实时监听 `wbo:worldbook-renamed`、`wbo:worldbook-deleted`、`wbo:settings-updated` 事件，支持一键直达整理面板。
- **统一 6 套低饱和配色**：内置「素纸」「青岚」「暖砂」「淡樱」「跟随酒馆」「深色夜间」，面板与悬浮球同步换色。
