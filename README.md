# User 人设点选（user-persona-picker）

打开就能直接点选拼出 User 人设的极简弹窗（酒馆助手全局脚本），PC 与手机竖屏通用。

## 怎么用（只需 2 步）

1. 在酒馆助手 →「全局脚本」导入 [`user-persona-picker-loader.json`](./user-persona-picker-loader.json) 并启用（以后刷新酒馆自动更新，不用重复导；离线版见 [`user-persona-picker.json`](./user-persona-picker.json)）。
2. 点输入栏旁的 **「User人设」**（或左下角魔棒菜单里的 **「User 人设」**）打开弹窗，直接勾选标签，按右下角 **「保存」** 即可。

## 三个标签页，一眼看懂

- **条目库**：内置 36 条常用外貌、性格、关系阶段、身份与互动规则，**打开就能点，不用自己写**；也可点 `+ 新建` 添加自己的设定，或点 `改正文` 直接修改任意条目内容。
- **世界书**：自动列出你酒馆里现有的世界书，点书名直接勾选里面的条目，**不用改世界书条目名**，支持搜索标题与正文。
- **方案**：把当前勾好的组合起个名字存成方案，下次一键「套用」切换；点星标 `☆` 可设为新聊天默认。

## 两种写入方式（底部二选一）

- **填入用户人设**（默认，零依赖）：直接写入当前 Persona 描述框（保留你原本写好的姓名/简介，只更新 `<USER人设>` 区块），无需任何额外插件或世界书。
- **仅当前聊天**（不同聊天互不串线）：保存到当前聊天变量，并自动生成与启用总控世界书 `User·总控入口`（需已安装 `ST-Prompt-Template`）。
