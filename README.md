# User 组装与快照（user-persona-picker）

适用于 SillyTavern / TauriTavern（PC + 手机竖屏）的 **酒馆助手（JS-Slash-Runner）** 全局脚本。

将「自由组装 User 人设与世界书条目」「查看/编辑预设与正则」「全量状态一键快照」「同名 User 防增殖整理」整合在同一个轻量液态玻璃面板中。

## 核心特点

- **全量一键快照**：自由勾选保存范围——**User 人设、世界书绑定与条目开关、预设与提示词开关、正则开关**；支持分组筛选、详情浮层查看并点击预览任意条目正文、覆盖更新、JSON 备份与导入。
- **按聊天 / 角色自动切回**：支持将快照绑定到当前聊天或当前角色（优先级：聊天 > 角色），切换聊天时自动切回绑定快照；顶部提供「自动切换」开关，默认开启，随时可暂停。
- **解决 User 增殖**：酒馆里每个名字只保留 **1 个** User Persona；同一名字的不同设定（如日常 / 现代 / 古风）作为**内部描述版本**保存在插件内，切换时原地更新描述并自动备份切换前内容，支持版本差异对比，并提供「整理分身」一键收回旧的同名/分身 User。
- **顺手的条目查看与组装**：世界书、预设、正则统一采用横行列表——点标题直接弹浮层看正文或就地修改，点右侧开关实时启停；支持世界书名搜索、正文搜索、只看已开、置顶常用世界书、一键全关、纯文本复制，以及未闭合/重复 XML 标签提示。
- **不改原文、不破坏格式**：快照仅记录引用与开关状态，应用时绝不覆盖修改过的世界书/预设/正则正文，也不向 Persona 拼接文本或强加外层标签。

## 安装方式

前置需求：已安装并启用 **酒馆助手（JS-Slash-Runner）**。

### 方式一：GitHub 自动更新壳（推荐，导入一次即可）

1. 下载本仓库的 `user-persona-picker-loader.json`。
2. 在酒馆助手 → 脚本库中导入该文件并启用。
3. 以后仓库更新时，刷新酒馆即可自动拉取最新版，无需反复重导。

### 方式二：离线单文件

1. 下载本仓库的 `user-persona-picker.json`。
2. 在酒馆助手 → 脚本库中导入并启用。

导入后，从酒馆扩展菜单点击 **「User 组装与快照」**，或点击脚本按钮 **「User人设」** 即可打开面板。
