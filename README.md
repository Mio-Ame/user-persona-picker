# User 人设点选（user-persona-picker）

打开就能直接点选拼出 User 人设的极简弹窗（酒馆助手全局脚本），PC 与手机竖屏通用。

## 怎么用（只需 2 步）

1. 在酒馆助手 →「全局脚本」导入 [`user-persona-picker-loader.json`](./user-persona-picker-loader.json) 并启用（以后刷新酒馆自动更新，不用重复导；离线版见 [`user-persona-picker.json`](./user-persona-picker.json)）。
2. 点输入栏旁的 **「User人设」**（或左下角魔棒菜单里的 **「User 人设」**）打开弹窗，勾选标签后按右下角 **「保存」**。

## 三个标签页

- **条目库**：内置 72 条常用设定（外貌与发色 / 穿搭与气质 / 性格底色 / 恋爱与依恋 / 表达方式 / 关系阶段 / 背景身份 / 互动规则），打开直接点选、免手写；点击任意标签即可在底部直接查看正文与点「编辑」，也可点 `+ 新建` 添加自定义条目。
- **世界书**：顶部下拉框直接选择酒馆里的任意世界书（只读拉取、不改原书开关；若该书已全局开启会提醒避免重复），点击任意标签即可查看/编辑正文，支持搜索标题与正文。
- **方案**：把当前勾好的组合起名存成方案，随时一键「套用 / 覆盖 / 删除」，点星标 `☆` 可设为新聊天默认，并提供写入用户人设前的原文一键恢复。

## 两种写入位置（底部二选一）

- **填入用户人设**（默认，零依赖）：点「保存」后先弹出确认预览页，默认**保留你原有简介、仅更新 `<USER人设>` 区块**（也可选择完整替换），并自动留一份写入前原文备份，不会误覆盖原有人设。
- **仅当前聊天**（按聊天隔离）：保存到当前聊天变量，并在后台自动创建/启用总控世界书 `User·总控入口`（需已安装 `ST-Prompt-Template`）。
