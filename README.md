# User 人设点选弹窗（user-persona-picker）

面向 SillyTavern / TauriTavern（PC 与手机竖屏）的通用 User 人设点选与管理弹窗（酒馆助手全局脚本）。

- **零命名要求、不改你的习惯**：直接绑定你现有的任意世界书，原名原序展示；粗颗粒大段人设默认「摘要卡片视图」一眼看清正文首行，细拆标签库自动切「紧凑标签视图」（可随时一键互切）。
- **不改原名也能自由归组**：想整理归类时，点条目编辑即可指定「插件内分组」与「注入位置（默认正文 / 写作规则 / 深度1强提醒）」，世界书原名纹丝不动；也支持按 `组名·名称` 自动归组。
- **方案快照**：像预设助手一样把当前勾选组合存为方案，支持「整套切换 / 仅替换单本书 / 叠加勾选」，并可任选一套作为新聊天默认勾选。
- **弹窗内原地编辑与搜索**：直接原地改标题和正文写回世界书，任意页签 `+ 新建` 条目，支持按标题与正文关键字搜索、实时预览最终拼接正文。
- **聊天级变量隔离**：勾选结果写入当前聊天的 `user_picker` 变量，不同聊天互不串线。
- **自适应液态玻璃外观**：自动适配酒馆浅色/深色主题，PC 居中弹窗、手机底部抽屉。

## 三步上手（一次导入，自动更新）

1. **导入远程更新壳**
   在酒馆助手 →「全局脚本」导入 [`user-persona-picker-loader.json`](./user-persona-picker-loader.json) 并启用（每次刷新酒馆自动同步本仓库最新版；若需离线版，也可导入 [`user-persona-picker.json`](./user-persona-picker.json)）。
2. **绑定世界书并一键启用总控**
   点输入栏旁的 **「User人设」** 按钮（或左下角魔棒菜单中的 **「User 人设点选」**）：
   - 绑定你现有的 User 世界书（若还没有，可点「从当前 Persona 导入新建」或「+ 新建空白人设书」）；
   - 点击 **「一键生成并启用」** 自动创建并全局开启总控世界书 `User·总控入口`（其余数据源书保持关闭即可）。
3. **点选并保存**
   勾选本次聊天想启用的设定（或直接切换已存方案），点底部 **「保存」**，下一轮对话立即生效。

## 进阶用法（全部可选）

- **视图与模式切换**：在页签工具栏可切换「摘要视图 / 标签视图」；在设置页可为每本书切换 `平铺` / `前缀归组` / `角色匹配`（角色匹配兼容 `【角色名】`、`[角色名]` 或标题直接包含角色名）。
- **深度 1 强提醒**：把任意避雷/底线条目在编辑页将「注入位置」设为「深度1强提醒」，无需改名为特定标题即可注入到深度 1。
- **跨设备同步**：点顶部齿轮 →「导出 JSON / 导入 JSON」，即可在电脑与手机间同步世界书绑定、自定义分组与方案快照。
