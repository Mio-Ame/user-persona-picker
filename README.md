# User 人设点选（user-persona-picker）

面向 SillyTavern / TauriTavern（PC 与手机竖屏）的通用 User 人设拼接与管理弹窗（酒馆助手全局脚本）。

## 快速使用

1. 在酒馆助手 →「全局脚本」导入 [`user-persona-picker-loader.json`](./user-persona-picker-loader.json) 并启用（刷新酒馆即自动更新；离线完整版见 [`user-persona-picker.json`](./user-persona-picker.json)）。
2. 点输入栏旁的 **「User人设」**（或魔棒菜单中的 **「User 人设」**）打开弹窗。
3. **点标签文字**可先看正文内容（不会误勾选），**点标签右侧圆圈**即可勾选/取消；配好后点右下角 **「应用 / 保存」**（或直接 **「复制文本」**）。

## 核心功能

- **结构化基础资料**：在「条目库 → 基础资料」填写或快选姓名、性别、年龄（输 `20` 自动补 `20岁`）、身高（输 `162` 自动补 `162cm`）、身份与外貌特征，留空项不输出。
- **单分类浏览 + 自定义分类**：内置 72 条常用设定按分类横向切换（页面紧凑不冗长），支持 `+ 分类` 自建分类与 `+ 新建` 自定义条目，支持全文搜索。
- **人设冲突提醒**：自动检测体型、发型、性格、关系阶段、时代背景等明显冲突，出现冲突时底部高亮提示并支持一键「只留最新」。
- **世界书双搜索**：支持先**搜世界书名**快速切书，再**搜当前书内条目**；只读拉取不改原书开关。
- **3 种输出格式 + 4 种导出方式**：在「应用 / 保存」页实时切换 **`YAML+自然语言` / `纯 YAML` / `自然语言`** 预览，支持：
  1. 更新当前用户人设（默认保留原有简介并自动留一份原文备份可恢复）；
  2. **另存为新的用户人设**（不改原有人设）；
  3. 仅当前聊天生效（聊天变量隔离，自动维护总控世界书 `order: 99999`）；
  4. **一键复制文本**。
- **方案快照**：把基础资料、已选条目与输出格式整套存为方案，随时一键「套用 / 覆盖 / 删除」或导出/导入跨设备同步。
