# User 人设点选弹窗（user-persona-picker）

面向 SillyTavern / TauriTavern（PC 与手机竖屏）的通用 User 人设模块化点选与管理工具（酒馆助手全局脚本）。

- **零硬编码、自由适配**：直接绑定你自己的任意世界书；条目按 `分组·名称` 自动归组（如 `性格·温柔`、`外貌·黑长直`），新增条目无需改代码。
- **方案快照**：像预设助手一样把当前勾选组合存为方案，支持「整套切换 / 仅替换单本书 / 叠加勾选」，并可任选一套作为新聊天默认勾选。
- **弹窗内原地编辑**：开启顶部编辑开关即可点击任意标签直接修改标题与正文并写回世界书，支持任意页签直接 `+ 新建` 条目与实时正文预览。
- **聊天级变量隔离**：勾选结果保存在当前聊天的 `user_picker` 变量中，不同聊天互不串线；配合总控世界书按需拉取正文，不占作者注释。
- **自适应液态玻璃外观**：自动识别酒馆浅色/深色主题，PC 居中弹窗、手机底部抽屉。

## 三步上手（推荐：一次导入，自动更新）

1. **导入远程更新壳**
   在酒馆助手 →「全局脚本」导入本仓库的 [`user-persona-picker-loader.json`](./user-persona-picker-loader.json) 并启用（以后刷新酒馆即可自动同步仓库最新版，无需重复导入；若偏好离线版本，也可导入 [`user-persona-picker.json`](./user-persona-picker.json)）。
2. **打开弹窗并一键初始化**
   点击输入栏旁的 **「User人设」** 按钮，或左下角魔棒菜单中的 **「User 人设点选」**：
   - 在引导页勾选存放 User 设定的世界书（支持区分「普通分组书」与「角色 IF 线书」）；
   - 点击 **「一键生成并启用」** 自动创建并全局开启总控世界书 `User·总控入口`（数据源世界书保持关闭即可）。
3. **点选并保存**
   勾选设定标签或切换已存方案，点底部 **「保存」**，下一轮对话自动生效。

## 命名小技巧（加新条目自动归组）

- **普通分组书**：按 `组名·条目名` 命名（如 `性格·腹黑`、`状态·失眠`、`阶段·暧昧拉扯`），弹窗会自动按前缀归进对应卡片；不带前缀的条目归入「常规」。
- **角色 IF 线书**：按 `【角色名】路线名` 或 `【通用】路线名` 命名，打开对应角色卡时自动筛选显示；以 `【模板】` 开头的规范条目不会混入选项列表。
- **配置跨设备同步**：点顶部齿轮图标 →「导出 JSON / 导入 JSON」，即可在电脑与手机之间同步已绑定世界书、方案快照与互斥规则。
