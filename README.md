# 快照管家（SillyTavern 原生扩展）

SillyTavern / TauriTavern（PC + 手机竖屏）原生扩展插件，通过扩展 URL 直接安装并支持酒馆内置更新。

## 安装方式

1. 打开 SillyTavern 的 **扩展（Extensions）** → **安装扩展（Install Extension）**。
2. 粘贴仓库地址：`https://github.com/Mio-Ame/user-persona-picker`
3. 安装完成后刷新页面。

入口位置：
- **快捷悬浮球**：默认吸附屏幕边缘，支持拖动贴边与位置记忆；轻点弹出「快捷切换快照」浮层，点快照名称查看详情，点右侧独立「应用」图标按钮才执行切换（防误触）。
- **魔法棒菜单 / 扩展设置**：点击 **「快照管家」** 打开完整面板。

## 核心特点

- **清晰 5 页组装 + 底部常驻保存栏**：`快照` / `User` / `世界书` / `预设` / `正则` 模块高度统一，固定尺寸弹窗不跳动，底部始终常驻「保存快照」与「更新当前快照」。
- **预设版本升级与批量同步（0.17 → 0.18 无损迁移 + 新条目一键同步）**：
  - 支持同预设新增条目一键批量同步到多份快照，以及预设跨版本迭代迁移（即使旧预设已被误删，快照内自动留存的条目 ID 与标题清单仍可完成自动匹配）；
  - 三级智能匹配：**ID 直连继承** → **归一化标题兜底匹配** → **手动关联改名换 ID 条目**；新增条目默认跟随你在酒馆原生预设界面勾选好的开关状态，并支持一键撤销上次同步。
- **User 搜索、原地改名与换姓防增殖**：
  - 在「User」页支持按关键词搜索所有 User 名称、内部版本名及人设正文内容；
  - 支持对当前 User **原地改名**（立即生效为 `{{user}}`，不新增分身），内部版本支持绑定不同显示名以实现一槽多姓；
  - 「整理分身」自动识别同名与同尾字换姓分身，一键收回为内部版本并同步删除后端头像文件，附带一键清理未命名残留头像。
- **预设分组默认折叠 + 条目原地展开**：
  - 预设分组默认收起（可在预设页顶栏或扩展设置中随时切换「默认折叠」开关），点击任意条目在正下方原地展开正文与编辑区。
- **快照编辑、显式保存与缺失项弥补**：
  - 支持编辑快照名称、分组与备注；快照详情页修改开关后提供明确的「保存修改」按钮，未保存时离开或应用会主动提醒；
  - 应用快照前自动核对 User、世界书与预设是否缺失：绝不删除快照，而是清晰列出缺失项，支持原地替换绑定、批量迁移旧预设、移除失效书引用、直达对应页面弥补，或跳过缺失项应用其余正常部分。
- **与 `worldbook-organizer` 双向解耦联动**：
  - 自动按分组、别名、自定义排除分组与角色世界书标题模式呈现世界书列表，选择世界书弹窗固定尺寸不跳动；
  - 实时监听 `wbo:worldbook-renamed`、`wbo:worldbook-deleted`、`wbo:settings-updated` 事件，支持一键直达整理面板。
- **统一 6 套低饱和配色**：内置「素纸」「青岚」「暖砂」「淡樱」「跟随酒馆」「深色夜间」，面板与悬浮球同步换色。
- **按聊天 / 角色自动切回**：支持绑定当前聊天或角色默认（优先级：聊天 > 角色），提供「自动切换」总开关（默认开启，随时可暂停）。
